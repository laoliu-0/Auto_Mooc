# Auto_Mooc

中国大学MOOC（ICOURSE163）自动答题油猴脚本，支持单元测试、课后小测试、SPOC 测验自动填答。

> 仅供学习浏览器自动化与用户脚本开发，请勿用于违规刷分。

## 功能

- 单元测试自动取题与填答
- 课后小测试一键执行
- SPOC 课后小测试自动完成
- 章节自动翻页
- 讨论题自动回复
- 视频内答题开关（可手动开启/关闭）
- 毛玻璃浮层面板，三个功能按钮

## 环境

- 浏览器：Chrome / Edge
- 插件：Tampermonkey 或 Violentmonkey
- 页面：
  - `https://www.icourse163.org/learn/*`
  - `https://www.icourse163.org/spoc/learn/*`

## 安装

1. 安装 Tampermonkey 浏览器插件
2. 新建用户脚本，清空默认代码
3. 将 `mooc_auto.js` 内容完整粘贴进去
4. 保存（Ctrl+S）
5. 打开 MOOC 课程章节页，右侧出现面板即生效

## 使用

1. 进入有测验的章节
2. 点击面板上的对应按钮：
   - 📝 单元测试
   - 📚 MOOC 课后小测试
   - 📚 SPOC 课后小测试
3. 脚本自动完成取题、匹配答案、勾选选项、提交
4. 如需在视频内答题，勾选面板上的“是否视频内答题”，并刷新页面
